# Kauã Segabinazzi

Software engineer moving into **gameplay programming**. I write C# for a living (.NET, since 2022) and build games in Python/Pygame, Unity and Unreal Engine 5.

## Games

| Project | What it is |
| --- | --- |
| **ChessMania** *(private)* | Chess roguelike in Unity 6 (C#). Score points with captures and checks to beat each round across five phases with boss rules, then spend gold in a shop on pieces, talismans and cards; Endless mode for after the last boss. Pure C# game core and minimax AI, covered by unit tests. |
| **Rush** *(private, in development)* | Third-person 3D movement platformer in Unity 6 (C#) built around speed: slope momentum, ground snapping, fast-fall, timed perfect landings and a dash, all driven by a movement state machine. Short time-trial levels with a ghost replay of your best run are next. Game-feel logic (coyote time, input buffering) is pure C# covered by unit tests. |
| [**BloodLost**](https://github.com/Kauasegabinazzi/BloodLost) | 2D castle action game written in Python with Pygame, no engine. Whip and knife combat, five stages, a Dracula boss fight, and colour-vision modes for colour-blind players. |
| [**Solar System**](https://github.com/Kauasegabinazzi/SolarSystem) | Interactive 3D solar system in Unity 6 (C#): orbits drawn from vector maths, click a planet to focus the camera. |
| [**Plane Game**](https://github.com/Kauasegabinazzi/Plane-Game) | Endless 2D flying game in Unity (C#) with difficulty that ramps up over time. |

Play them on [itch.io](https://kaluhnat.itch.io). Environment art in Unreal Engine 5 is on [ArtStation](https://www.artstation.com/kaluhnat).
